**Machine learning (ML)** builds systems that improve at a task from data rather than purely hand-coded rules. You choose a model class, a loss (or reward), and an optimization procedure; performance is measured on held-out data.

### Main paradigms
- **[Supervised learning](/ai-glossary/supervised-learning/)** — predict labels from features
- **[Unsupervised learning](/ai-glossary/unsupervised-learning/)** — structure without labels (clustering, density)
- **[Self-supervised learning](/ai-glossary/self-supervised-learning/)** — labels from the input itself (next-token, masking)
- **[Reinforcement learning](/ai-glossary/reinforcement-learning/)** — maximize reward via interaction

### Where LLMs sit
LLMs are large-scale self-supervised [neural networks](/ai-glossary/neural-network/) ([deep learning](/ai-glossary/deep-learning/)) adapted with supervised instruction data and preference/RL methods. Classical ML (trees, linear models) still wins on many tabular problems; use the simplest method that meets the metric.
