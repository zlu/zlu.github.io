A **vector database** stores high-dimensional embeddings and supports similarity search (often approximate nearest neighbor). It is the retrieval backend for many RAG systems.

Features often include metadata filters, hybrid sparse+dense search, and collections/namespaces for multi-tenant apps. Examples of the ecosystem include FAISS, HNSW indexes, and managed vector stores.
