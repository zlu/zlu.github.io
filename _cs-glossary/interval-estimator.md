An **interval estimator** for $\theta$ is a pair of statistics $[g_L(X),g_U(X)]$ producing a random interval. A [confidence interval](/cs-glossary/confidence-interval/) is an interval estimator designed so its [coverage probability](/cs-glossary/coverage-probability/) meets a target [confidence coefficient](/cs-glossary/confidence-coefficient/) $1-\alpha$.

Contrast [point estimation](/cs-glossary/point-estimation/), which returns a single number $\hat\theta$.
