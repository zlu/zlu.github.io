A **hypothesis** is a statement about a population [parameter](/cs-glossary/parameter/). In classical testing we contrast a [null](/cs-glossary/null-hypothesis/) $H_0$ with an [alternative](/cs-glossary/alternative-hypothesis/) $H_1$.

[Simple](/cs-glossary/simple-hypothesis/) hypotheses pin $\theta$ to one value; [composite](/cs-glossary/composite-hypothesis/) hypotheses allow a set of values. Testing uses a [test statistic](/cs-glossary/test-statistic/) and a [critical region](/cs-glossary/critical-region/).
