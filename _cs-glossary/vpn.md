A **VPN** (virtual private network) encrypts traffic between your device (or a home gateway) and a remote endpoint so it can traverse an untrusted [WAN](/cs-glossary/wan/) as if on a private link.

Home lab boxes often run a VPN **client** ([WireGuard](/cs-glossary/wireguard/), OpenVPN) next to file / media services so the always-on host, not every phone, holds the tunnel.
