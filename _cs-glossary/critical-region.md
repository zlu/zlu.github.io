The **critical region** (rejection region) $R$ is the set of sample outcomes / [test-statistic](/cs-glossary/test-statistic/) values for which we reject $H_0$. Its complement is the **acceptance region**.

Chosen so that the [Type I](/cs-glossary/type-i-error/) error / [size](/cs-glossary/significance-level/) equals a target $\alpha$ (e.g. $0.05$). Equivalently: reject when the [$p$-value](/cs-glossary/p-value/) $\le\alpha$.
