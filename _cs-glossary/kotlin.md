**Kotlin** is a statically typed JVM (and multiplatform) language from JetBrains. Null-safety in the type system, concise syntax, full [Java](/cs-glossary/java/) interop. Default for modern Android; also used with [Spring](/cs-glossary/spring/).

```kotlin
fun greet(name: String): String = "hello, $name"

fun main() {
    println(greet("world"))
}
```
