**[OpenWrt](https://openwrt.org/)** is an open-source Linux distribution for routers and embedded boards: writable rootfs, `opkg` packages, and the **LuCI** web UI. You flash a board image, then install what you need (miniDLNA, [WireGuard](/cs-glossary/wireguard/), Samba).

China-oriented forks and appliances ([ImmortalWrt](/cs-glossary/immortalwrt/), [iStoreOS](/cs-glossary/istoreos/), cooluc R5S builds) are OpenWrt-family images with different defaults and UIs. Official project: [openwrt.org](https://openwrt.org/).
