**Next.js** is a [React](/cs-glossary/react/) framework on [Node.js](/cs-glossary/nodejs/) for routed apps: server and client components, file-based routing, and data fetching conventions. Same client hooks (`useState`, `useEffect`) as React for interactive UI.

```tsx
// app/page.tsx
export default function Page() {
  return <h1>hello, world</h1>;
}
```
