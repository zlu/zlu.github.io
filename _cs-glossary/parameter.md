A **parameter** $\theta\in\Omega_\theta$ is an unknown constant indexing a probability model $f_{X\mid\theta}$. Estimation targets $\theta$ (or a function $g(\theta)$) from data.

Examples: mean $\mu$, variance $\sigma^2$, regression slopes $\beta$. An [estimator](/cs-glossary/estimator/) $W=w(X)$ is a rule; an [estimate](/cs-glossary/estimate/) $w(x)$ is the number once data are plugged in.
