**UDP** (User Datagram Protocol) is an unreliable, connectionless transport over IP. No handshake, no built-in retransmission. [QUIC](/cs-glossary/quic/) and [WireGuard](/cs-glossary/wireguard/) run on UDP; classic HTTPS uses [TCP](/cs-glossary/tcp/).
