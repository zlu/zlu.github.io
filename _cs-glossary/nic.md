A **NIC** (network interface card / controller) is a physical Ethernet (or other) network port on a host. “Dual-NIC” / “multi-NIC” boards expose two or more ports so one can face the upstream [LAN](/cs-glossary/lan/) and another can face a downstream segment, or so you can run a [bypass router](/cs-glossary/bypass-router/) without stealing the Wi‑Fi AP’s only uplink.

The [NanoPi R5S](https://wiki.friendlyelec.com/wiki/index.php/NanoPi_R5S) is a common example: multiple Ethernet ports on a small ARM board meant for gateway / side-router duty.
