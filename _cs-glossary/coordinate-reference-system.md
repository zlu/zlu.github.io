A **coordinate reference system** (CRS) defines how coordinates map to places on Earth — datum + projection (or geographic lon/lat).

Wrong CRS ⇒ wrong distances and mismatched layers. Transport stacks often mix [WGS84](/cs-glossary/wgs84/) (GPS) with local projected metres for analysis.
