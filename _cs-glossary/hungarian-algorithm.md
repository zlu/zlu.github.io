The **Hungarian algorithm** (Kuhn–Munkres) solves the $n\times n$ [assignment problem](/cs-glossary/assignment-problem/) in polynomial time by reducing the cost matrix with row/column operations and covering zeros until an optimal set of independent zeros appears.

Uses the theorem that adding a constant to any row or column does not change the optimal assignment.
