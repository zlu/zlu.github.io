**Ruby** is a dynamically typed OOP language with heavy message-send / block idioms. Syntax and object model are influenced by [Smalltalk](/cs-glossary/smalltalk/) and Perl. [Ruby on Rails](/cs-glossary/ruby-on-rails/) is the dominant web framework.

```ruby
def greet(name)
  "hello, #{name}"
end

puts greet("world")

[1, 2, 3].map { |n| n * 2 }
```
