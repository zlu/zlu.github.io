**FTP** (File Transfer Protocol) is an older file-transfer stack ([TCP](/cs-glossary/tcp/) 21 for control). Some ISP gateway firmwares expose USB storage over FTP only, with no working [Samba](/cs-glossary/samba/)/SMB on port 445.

Fine for a manual download test; awkward for Finder browse and useless for [DLNA](/cs-glossary/dlna/) discovery in an app like Lume.
