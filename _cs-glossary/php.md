**PHP** is a dynamically typed language built for server-side web pages. Still widely deployed for CMS and API backends; [Laravel](/cs-glossary/laravel/) is a popular modern framework.

```php
<?php
function greet(string $name): string {
    return "hello, {$name}";
}

echo greet("world");
```
