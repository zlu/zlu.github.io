The **raster** data model represents space as a regular grid of cells/pixels, each holding an attribute (elevation, land cover, temperature).

Strong for continuous fields, interpolation, and image-like processing (`.tif`, `.jpg`). Network topology is awkward compared with [vector](/cs-glossary/vector-data-model/) roads.
