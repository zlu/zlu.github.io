**Sample space** $\Omega$ is the set of all possible outcomes of a random [experiment](/cs-glossary/experiment/). Each outcome is a sample point $\omega\in\Omega$. An [event](/cs-glossary/event/) is a subset $E\subseteq\Omega$.

Classify $\Omega$ before computing probabilities: **discrete** (countable — coin sequences, counts) vs **continuous** (an interval — lifetimes, weights). Write “Experiment = … ; $\Omega$ = …” on exam answers.

Special events: $\Omega$ (certain) and $\emptyset$ (impossible).
