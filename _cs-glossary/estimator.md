An **estimator** $W=w(X_1,\ldots,X_n)$ is a rule — a function of the [random sample](/cs-glossary/random-sample/) — for guessing a parameter $\theta$. It is a random variable. The numerical value $w(x)$ on observed data is an **[estimate](/cs-glossary/estimate/)**.

Same hat notation $\hat\theta$ is often used for both; context decides. Construct estimators via [method of moments](/cs-glossary/method-of-moments/) or [MLE](/cs-glossary/maximum-likelihood/); evaluate via [bias](/cs-glossary/bias/), [MSE](/cs-glossary/mean-squared-error/), and [consistency](/cs-glossary/consistency/).
