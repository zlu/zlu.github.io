**Swift** is Apple’s statically typed language for Apple platforms (and some server use). Optionals, value types, and ARC memory management. Replaces much new [Objective-C](/cs-glossary/objective-c/) code.

```swift
func greet(_ name: String) -> String {
    return "hello, \(name)"
}

print(greet("world"))
```
