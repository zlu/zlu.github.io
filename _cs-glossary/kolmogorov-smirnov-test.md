The **Kolmogorov–Smirnov** (K–S) test compares an empirical CDF to a reference CDF (often Normal). In regression diagnostics: $H_0$: residuals ~ Normal; fail to reject if [$p$](/cs-glossary/p-value/) is large (e.g. $>0.05$).

Complement visual [Q–Q](/cs-glossary/qq-plot/) checks. Sensitive in large $n$; always pair with plots.
