**JavaScript** is the scripting language of web browsers (and, via [Node.js](/cs-glossary/nodejs/), servers). Dynamic typing, first-class functions, prototype-based objects, event-loop concurrency.

```javascript
const greet = (name) => `hello, ${name}`;
console.log(greet("world"));

button.addEventListener("click", () => {
  console.log("clicked");
});
```
