A **composite hypothesis** does not fix a single distribution — it is a set of parameter values, e.g. $H_0:\theta\le\theta_0$ or $H_1:\theta\neq\theta_0$.

Size is then defined as the supremum of Type I error over the null set; power is a function of $\theta$ under the alternative. Most regression “$H_0:\beta=0$” probes are simple in $\beta$ but composite once $\sigma^2$ is unknown (handled via $t$).
