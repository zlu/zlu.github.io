A **sample outcome** $\omega$ is one possible result of an [experiment](/cs-glossary/experiment/). The set of all outcomes is the [sample space](/cs-glossary/sample-space/) $\Omega$. An [event](/cs-glossary/event/) is a designated collection of outcomes.

A [random variable](/cs-glossary/random-variable/) maps each $\omega$ to a real number $X(\omega)=x$.
