**Python** is a dynamically typed, garbage-collected language with significant indentation and a large standard library. Common for scripting, data work, web backends ([Django](/cs-glossary/django/)), and ML tooling.

```python
def greet(name: str) -> str:
    return f"hello, {name}"

print(greet("world"))
```
