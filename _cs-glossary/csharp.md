**C#** is a statically typed OOP / multi-paradigm language on [.NET](/cs-glossary/dotnet/). Common for Windows apps, game tooling (Unity), and ASP.NET web services.

```csharp
using System;

static string Greet(string name) => $"hello, {name}";

Console.WriteLine(Greet("world"));
```
