An **event** $E$ is a specified collection of outcomes: $E\subseteq\Omega$. The event occurs if the realised outcome $\omega$ lies in $E$.

Combine events with union $E\cup F$, intersection $E\cap F$, and complement $E'$. **Mutually exclusive** (disjoint) events satisfy $E\cap F=\emptyset$, so probabilities add with no overlap term. De Morgan: $(E\cup F)'=E'\cap F'$.

[Probability axioms](/cs-glossary/probability-axioms/) assign $P(E)\in[0,1]$ with $P(\Omega)=1$.
