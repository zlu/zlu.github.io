**APFS** (Apple File System) is macOS’s default volume format for internal and many external disks. Consumer ISP gateways and cheap [Samba](/cs-glossary/samba/) boxes run embedded Linux and almost never mount APFS. Reformat to [ExFAT](/cs-glossary/exfat/) or [FAT32](/cs-glossary/fat32/) before plugging the disk into an [ONT](/cs-glossary/ont/) USB port.
